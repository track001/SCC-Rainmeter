# SCC Rainmeter Widgets

A collection of lightweight, modular desktop widgets built with **Rainmeter** for Sport Climbing Center (SCC) staff.

Developed by **Ti Schwarz**, these widgets provide quick access to gym tools, competition resources, and staff utilities directly from the Windows desktop.

## Included Widgets (v8)

| Widget | Description |
|---|---|
| **SOP Hub** | Quick access to SCC's [Operations SOP Hub](https://track001.github.io/Battle-of-Brawn-2025-Competition-System/) and staff resources. |
| **MySQL Status** | Displays database connection status for SCC's internal tools. |
| **Climbing Noise Timer** | Opens the [Climbing Noise Timer](https://climbingnoise.com/timer). Displays event name `Brawn` and code `070820`. |
| **Brawn 2026 Results** | Quick access to [Battle of Brawn 2026 results](https://track001.github.io/Battle-of-Brawn-2025-Competition-System/#brawn2026/overview), with separate buttons for Open Qualifiers, Citizens, and Open Finals. |

Each widget can be loaded, unloaded, and positioned independently through Rainmeter.

## Installation

1. Download `SCC-Rainmeter-Widgets-v8.zip` from this repository.
2. Extract the `SCC-Widgets` folder into:
   ```
   Documents\Rainmeter\Skins
   ```
3. Open Rainmeter and select **Refresh all**.
4. Load the desired `.ini` configurations.

**Requirements:** Windows and [Rainmeter](https://www.rainmeter.net/).
